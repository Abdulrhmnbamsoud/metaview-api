# MetaView 3 — Global News Intelligence Platform

منصة استخبارات ورصد إخباري عالمي، تجمع الأخبار الموثوقة من مصادر متعددة عبر خلاصات RSS، وتعالجها وتخزنها في قاعدة بيانات متصلة عبر FastAPI، مع واجهة تفاعلية فاخرة تشبه مراكز العمليات والاستخبارات الدولية.

---

## 🏛️ البنية الأساسية (Architecture)

المشروع يتبع بنية الفصل النظيف والمصدر الوحيد للحقيقة (Single Source of Truth):
```
News Sources (RSS) ➔ Image Scraper ➔ SQLite DB ➔ FastAPI Backend (:8000) ➔ React + Vite Frontend (:5173)
```

1. **الـ Backend (خادم MetaView API)**:
   - مكتوب بـ Python / FastAPI.
   - قاعدة بيانات SQLite مدمجة في `backend/data/metaview.db`.
   - وحدة استخراج الصور المستقلة `app/image_scraper.py` (متوافقة مع RSS Media, Enclosures, Open Graph, و Twitter Card).
   - توفير Endpoints موثقة عبر Swagger UI على `http://127.0.0.1:8000/docs`.

2. **الـ Frontend (منصة MetaView 3)**:
   - مبني بواسطة React 18, TypeScript, Vite, و Tailwind CSS.
   - هوية بصرية ملكية داكنة (Royal Dark Intelligence: أسود ملكي، كحلي رمادي، لمسات ذهبية `#C5A059`).
   - لا توجد أي بيانات وهمية (No Mock Data)؛ كافة الأرقام، المخططات، والبطاقات مستمدة 100% من الـ API الحقيقي.

## 📑 صفحات ووحدات المنصة (Modules)

1. **لوحة القيادة العالمية (Dashboard)**:
   - المؤشرات الأربعة الرئيسية: إجمالي المقالات، المصادر النشطة، مقالات آخر 24 ساعة، وآخر توقيت للتحديث.
   - الرسم البياني الزمني (Timeline Chart) لوتيرة النشر.
   - مخطط توزيع المصادر (Source Coverage Share).
   - شريط الكلمات والموضوعات الأكثر تكراراً في العناوين الحقيقية.
   - موجز أحدث الأخبار (Latest Feed) مع الصور والبطاقات التفاعلية.

2. **مستكشف الأخبار (News Explorer)**:
   - البحث بالكلمات المفتاحية عبر العناوين والملخصات.
   - الفلترة متعددة الأبعاد (المصدر، بلد المصدر، نطاق التاريخ).
   - الفرز والتنقل بين الصفحات (Pagination).
   - بطاقات إخبارية ذكية مع روابط المصدر ونسخ الرابط ومعاينة السجل بالكامل في Modal.

3. **الخريطة العالمية (Global Intelligence Map)**:
   - خريطة تفاعلية للشبكة الإخبارية مع نقاط ارتكاز للدول.
   - تطبيق قاعدة التمييز الصارمة: **Source Country** (بلد الناشر) مقابل **Event Country** (موقع الحدث).
   - استعراض الأخبار المرتبطة بكل دولة عند النقر على علامتها.

4. **مركز العمليات (Operations Center)**:
   - لوحة مراقبة حية لحالة الخادم وقاعدة البيانات وسرعة الاستجابة.
   - زر التشغيل الفوري لدورة الرصد والتحديث عبر `POST /ingest/run`.
   - جدول تفصيلي يوضح حالة كل قناة (المسترجع، المضاف، المكرر، استخراج الصور، والزمن بالثواني).

5. **مستودع الأخبار الموحد (Unified News Repository)**:
   - جدول بيانات مكثف (Data Grid) عالي الكفاءة يشبه منصات Bloomberg و Palantir.
   - فرز فوري للأعمدة والبحث السريع.
   - تصدير كامل البيانات إلى ملف CSV يدعم اللغة العربية بواسطة ترميز UTF-8 BOM.

6. **تحليل المصادر (Source Intelligence)**:
   - مقارنة بصرية لحصص التغطية الإخبارية لوكالات رويترز، بي بي سي، سي إن إن، لوموند، دويتشه فيله وغيرها.
   - تفاصيل روابط التغذية الحية ومعدلات النشر الزمني.

7. **طبقة الذكاء الاصطناعي (AI Intelligence Layer)**:
   - المعمارية الهندسية الشفافة للخدمات المخططة (البحث الدلالي، تجميع الأحداث، تحليل النبرة، الترجمة، المقارنة التحريرية).
   - توضيح نقاط الاتصال ونماذج الطلب والاستجابة بدون اختلاق نتائج وهمية.

## 🖼️ وحدة استخراج صور الأخبار (`backend/app/image_scraper.py`)

تم بناء وحدة مستقلة وخاصة لاستخراج الصور الحقيقية للمقالات بناءً على الأولويات التالية:
1. `media:content` في خلاصة RSS.
2. `media:thumbnail` في خلاصة RSS.
3. وسائط `enclosure` ذات صيغ الصور.
4. وسوم `<img>` داخل ملخص الخبر.
5. استخراج وسوم Open Graph (`og:image`) من صفحة المقال.
6. استخراج وسوم Twitter Card (`twitter:image`).
7. حماية مشددة من ثغرات SSRF وفلترة الصور الصغيرة والشعارات غير المناسبة.
8. صورة بديلة (High-End Dark Placeholder) فاخرة عند تعذر توفر صورة للمقال، دون اختلاق صور إخبارية مضللة.
